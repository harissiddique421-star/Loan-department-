The Tooba Foundation runs this website to process interest-free loan applications. This page explains what information it keeps and how it is protected.

Information we keep

Details that applicants give on the loan form (name, father/husband name, CNIC, phone numbers, address, business, income and expenses, guarantor details), their photos and CNIC pictures and other uploaded documents, loan and disbursement records, and the names and actions of the staff who use the system.

How it is used

Only to assess, approve, disburse and track interest-free loans, and to keep the Foundation's records. It is never sold, never used for advertising and never shared with anyone outside the Foundation unless the law requires it.

Where it is stored

In the Foundation's private database (Supabase). Backup copies — filled application forms in Microsoft Word format and complete database backups — are saved in the Foundation's own Google Drive account.

Google account access

When an administrator connects Google Drive, the system asks only for permission to create and manage the files it makes itself (the drive.file permission) and to know the connected email address. It cannot see any other files in that Google Drive. The sign-in token is kept encrypted on the server and is never shown in any web page. Google user data is used only to store and check these backups, is not shared with anyone, and is not used for any other purpose. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Access can be removed at any time from the Backup & Recovery page or at myaccount.google.com/permissions.

Security

Only logged-in staff can see application data, each according to their role. Passwords are stored hashed, connections use HTTPS, and every change is recorded in an audit log.

Your rights

Applicants may ask the Foundation to see or correct their information.
